# David Ogbogu — Portfolio Website

A modern, high-performance, and bespoke portfolio website for **David Ogbogu** (Webdesigner & Digital Product Designer), crafted with semantic HTML5, Vanilla CSS3 with CSS Custom Properties for full Light/Dark mode inversion, and lightweight Vanilla JavaScript.

---

## ✨ Features

- **Cinematic Startup Sequence:** Dramatic display typography entrance for `David—Ogbogu` with a pronounced zoom-in and motion-blur transition into the site.
- **Dynamic Hero Section:** Massive display typography (`DAVID` in outlined stroke style, `OGBOGU` in solid bold fill) integrated with a feathered transparent portrait cutout.
- **Light / Dark Mode Switcher:** Stylish animated Sun/Moon toggle with persistent preference and complete color inversion.
- **Selected Work Showcase:** Interactive project gallery with category filtering (`All`, `Real Project`, `Exploration`) and hover lift effects.
- **Interactive Services Accordion:** Expandable service cards with rich descriptions and multi-device preview mockups.
- **Experience Timeline:** Clean career timeline featuring cursor-following floating project preview cards on hover.
- **Interactive Contact Modal:** Sleek popup drawer with a validated project inquiry form.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic & SEO-optimized, OpenGraph, JSON-LD Schema)
- **Styling:** Vanilla CSS3 (Custom Properties / Design Tokens, Flexbox, CSS Grid, Glassmorphism)
- **Scripting:** Vanilla JavaScript (ES6 Modules, LocalStorage Theme Persistence, DOM Animations)
- **Typography:** Google Fonts (`Outfit`)

---

## 🚀 Getting Started

To run the portfolio locally:

```bash
# Clone the repository
git clone https://github.com/itsjust-dave/website_demo_1_portfolio_1.git

# Navigate to project directory
cd website_demo_1_portfolio_1

# Start a local web server (e.g. with Python)
python -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
