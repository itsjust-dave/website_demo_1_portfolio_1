## 🚀 How to View Locally

Simply double-click `index.html` to open it directly in any modern browser, or run a local HTTP server:

```bash
# Using Python
python -m http.server 8080

# Using Node / npx
npx serve .
```

Open `http://localhost:8080` in your web browser.
